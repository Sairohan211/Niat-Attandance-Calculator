# NIAT x CDU Attandance Calculator

A fast, client-side, mobile-first web application designed for university students to calculate and project their attendance for the remaining 14 working days (including normal classes and GRIT examination days).

## Features
- **100% Client-Side & Manual**: No AI, backend, database, or external APIs. All mathematical calculations run instantly and securely in your browser.
- **Fixed Configuration**:
  - 14 remaining working days (10 normal days + 4 GRIT days)
  - 8 sessions per day (112 total future sessions)
  - 70% minimum attendance benchmark
- **GRIT Exam Participation Support**:
  - Writing GRIT: 112 / 112 possible future attended sessions.
  - Not Writing GRIT: 100 / 112 possible future attended sessions (5 of 8 sessions count on GRIT days).
- **Comprehensive Attendance Insights**:
  - Current attendance percentage
  - Maximum possible projected attendance
  - Missable sessions calculator (maintaining ≥ 70%)
  - Progress bar and detailed breakdowns
- **Sleek, Responsive UI**: Dark theme, smooth micro-animations, and mobile-first design.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla ES6+)
